Apple Silicon Mac에서 방해 없이 스크린샷을 캡처하고 화면을 녹화할 수 있는 네이티브 앱입니다. SwiftUI, AppKit, ScreenCaptureKit, AVFoundation으로 제작했으며, 서드파티 의존성이 없습니다.

## 실행

macOS 14 이상이 설치된 Apple Silicon Mac이 필요합니다.

`build/EZSnapshot-1.0-Apple-Silicon.dmg`로 설치하려면 디스크 이미지를 열고 **EZSnapshot**을 **응용 프로그램**으로 드래그하세요. 또는 `build/EZSnapshot-1.0-Apple-Silicon.zip`의 압축을 풀고 `EZSnapshot.app`을 **응용 프로그램**으로 옮기세요. 로컬에서 빌드한 경우 `build/EZSnapshot.app`을 바로 열 수 있습니다.

처음 캡처할 때 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 EZSnapshot을 허용하세요. 이전 macOS 버전에서는 **화면 기록**으로 표시됩니다. EZSnapshot으로 돌아오세요. macOS에서 앱을 다시 열도록 요청할 수 있습니다.

## 캡처

- **영역:** 드래그하여 캡처할 영역을 선택합니다.
- **윈도우:** macOS 기본 선택기를 사용해 윈도우를 선택합니다.
- **전체 화면:** 기본 디스플레이를 캡처합니다.
- **Escape:** 선택 중인 캡처를 취소합니다.
- EZSnapshot이 실행 중일 때 사용하는 전역 단축키: **Control + Option + 1**(영역), **Control + Option + 2**(윈도우), **Control + Option + 3**(전체 화면).
- 앱 윈도우, 메뉴 막대 또는 전역 단축키로 캡처할 수 있습니다.

스크린샷은 기본적으로 `~/Pictures/EZSnapshot`에 저장됩니다. macOS 기본 캡처 도구가 전용 임시 디렉터리에 이미지를 저장하면, EZSnapshot이 이미지를 확인하고 선택한 폴더로 내보냅니다. 설정에서 저장 폴더, PNG/JPEG 형식, 캡처 지연 시간, 전체 화면 캡처 시 포인터 포함 여부를 변경할 수 있습니다.

로컬 보관함에서는 검색, 즐겨찾기, 복사, 공유, 내보내기, 이름 변경, Finder에서 보기, 스크린샷을 휴지통으로 이동하는 기능을 제공합니다. 주석 편집기에는 펜, 사각형, 타원, 화살표, 색상, 선 굵기, 실행 취소 기능이 있습니다. 편집 내용을 저장하면 원본 픽셀 해상도를 유지한 별도의 이미지가 생성됩니다.

## 화면 녹화

사이드바에서 **화면 녹화**를 여세요. 디스플레이 또는 윈도우를 선택하세요. 특정 영역을 녹화하려면 디스플레이를 선택한 뒤 녹화할 영역을 지정하세요. 초당 30 또는 60프레임, 시스템 오디오 포함 여부, 포인터 표시 여부를 설정한 다음 **녹화 시작**을 누르세요.

녹화 중에는 메인 윈도우가 숨겨집니다. 메뉴 막대에는 1초마다 갱신되는 경과 시간과 **녹화 중지** 항목이 표시됩니다. 인코더 준비와 미디어 파일 저장 처리는 백그라운드에서 실행되므로 인터페이스가 계속 원활하게 반응합니다. **Control + Option + 4**로 어디서든 녹화를 시작하거나 중지할 수 있습니다. 메인 윈도우를 다시 열면 윈도우의 중지 버튼도 사용할 수 있습니다. 녹화 중 앱을 종료하려고 하면 먼저 녹화를 중지하고 저장할 수 있도록 안내합니다.

녹화는 스크린샷과 동일하게 선택한 폴더에 H.264 MP4 동영상으로 저장되며, 오디오를 활성화하면 AAC 오디오가 포함됩니다. 시스템 오디오는 선택한 녹화 대상에 따라 캡처되며, 마이크 오디오는 캡처하지 않습니다. 보관함은 macOS 기본 동영상 재생, 썸네일, 재생 시간, 즐겨찾기, 공유, 복사, 이름 변경, 내보내기, 휴지통으로 이동하는 기능을 제공합니다. 동영상 내보내기는 전체 동영상을 메모리에 불러오지 않고 백그라운드에서 파일을 복사합니다.

Retina 동영상은 긴 쪽 기준 최대 4096픽셀까지 원본의 세부 정보를 유지하며, H.264에 맞춰 가로와 세로 크기를 짝수로 맞춥니다. 캡처 스트림이 중단되면 사용할 수 있는 프레임으로 동영상 파일을 완성합니다. 내용이 없거나 실패한 녹화는 보관함에 추가하지 않으며, 기존 스크린샷과의 호환성도 유지됩니다.

녹화와 재생에는 macOS에 포함된 프레임워크를 사용합니다. **FFmpeg, Homebrew, 다운로드한 코덱, 추가 런타임 설치가 필요하지 않습니다.** 모든 앱 코드는 앱 번들에 포함되어 있습니다.

## 언어와 화면 스타일

설정에서 국기가 표시된 언어 항목을 선택할 수 있습니다. 지원 언어는 영어(미국), 중국어 간체(중국), 중국어 번체(대만), 일본어(일본), 한국어(대한민국), 프랑스어(프랑스), 독일어(독일), 스페인어(스페인)입니다. 기본 언어는 Mac의 선호 언어 중 지원되는 언어를 따르며, 해당 언어가 없으면 영어를 사용합니다. 변경 사항은 즉시 적용되며 앱을 다시 실행해도 유지됩니다.

라이트 모드, 다크 모드, 시스템 설정에 따르는 화면 스타일을 사용할 수 있습니다. 스크린샷과 보관함 메타데이터는 Mac에 저장되며, 앱은 네트워크 요청을 보내지 않습니다.

## 빌드

Xcode 또는 Apple의 Command Line Tools를 설치한 다음 아래 명령을 실행하세요.

```sh
python3 Tools/build.py
```

이 명령은 `build/EZSnapshot.app`을 생성하고, 아이콘과 현지화 리소스를 추가하며, 로컬 서명을 적용하고 설치 프로그램의 그래픽을 준비합니다. 소스에는 IDE에서 사용할 수 있는 Swift Package도 포함되어 있습니다. `swift build`를 실행하면 실행 파일이 생성됩니다. 빌드 스크립트는 일반적인 macOS 실행과 개인정보 보호 권한 처리에 필요한 전체 앱 번들을 생성합니다.

디자인이 적용된 드래그 앤 드롭 설치 프로그램을 패키징하려면 빌드 전용 패키징 도구를 한 번 설치한 다음 DMG를 생성하세요.

```sh
python3 -m pip install --target .build/dmg-python -r Tools/requirements-dmg.txt
python3 Tools/make_dmg.py
```

결과물은 `build/EZSnapshot-1.0-Apple-Silicon.dmg`입니다. 배포 전에 앱 서명과 디스크 이미지 체크섬을 검증합니다. 패키징 도구는 앱에 포함되지 않으며 앱 실행에도 필요하지 않습니다.

다른 툴체인을 사용하려면 `EZSNAPSHOT_TOOLCHAIN`을 해당 툴체인의 `usr/bin` 디렉터리로, `EZSNAPSHOT_SDK`를 Mac SDK 디렉터리로 설정하세요.

현지화, Retina 내보내기, 스크린샷 저장, macOS 기본 H.264/AAC 인코딩, 보관함 호환성, 미디어 내보내기, 리소스 검사를 실행하려면 아래 명령을 사용하세요.

```sh
python3 Tools/check.py
```

인코딩 검사는 합성 프레임과 오디오를 사용하므로 화면 기록 권한이 필요하지 않습니다. 자동화된 샌드박스 환경에서는 Apple의 동영상 및 오디오 인코딩 서비스에 대한 접근을 허용해야 합니다. 실제 화면 캡처에는 macOS 권한이 필요합니다.

포함된 앱은 로컬 임시 서명(ad-hoc)을 사용합니다. 공개 배포하려면 Apple Developer ID로 서명하고 공증을 받아야 합니다.
