Apple Silicon Mac向けの、作業を邪魔しないネイティブのスクリーンショット・画面収録アプリです。SwiftUI、AppKit、ScreenCaptureKit、AVFoundationで構築されており、サードパーティの依存ライブラリはありません。

## 起動

macOS 14以降を搭載したApple Silicon Macが必要です。

`build/EZSnapshot-1.0-Apple-Silicon.dmg`からインストールする場合は、ディスクイメージを開き、**EZSnapshot**を「**アプリケーション**」にドラッグしてください。`build/EZSnapshot-1.0-Apple-Silicon.zip`を展開し、`EZSnapshot.app`を「**アプリケーション**」に移動することもできます。ローカルでビルドした場合は、`build/EZSnapshot.app`を直接開けます。

初めて撮影するときは、「**システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音**」でEZSnapshotを許可してください（以前のmacOSでは「**画面収録**」という名称です）。その後、EZSnapshotに戻ります。macOSからアプリを開き直すよう求められる場合があります。

## スクリーンショット

- **範囲：**ドラッグして撮影する範囲を選択します。
- **ウインドウ：**macOS標準の選択機能でウインドウを選びます。
- **画面全体：**メインディスプレイを撮影します。
- **Escape：**範囲やウインドウの選択中に撮影をキャンセルします。
- EZSnapshotの起動中はグローバルショートカットを使用できます。**Control + Option + 1**（範囲）、**Control + Option + 2**（ウインドウ）、**Control + Option + 3**（画面全体）。
- アプリのウインドウ、メニューバー、グローバルショートカットから撮影できます。

スクリーンショットは標準で`~/Pictures/EZSnapshot`に保存されます。macOS標準の撮影ユーティリティが非公開の一時ディレクトリに画像を書き込み、EZSnapshotが画像を検証してから指定したフォルダに書き出します。「設定」では、保存先フォルダ、PNG/JPEG形式、撮影の遅延、画面全体の撮影にポインタを含めるかどうかを変更できます。

ローカルのライブラリでは、検索、お気に入り、コピー、共有、書き出し、名前の変更、Finderでの表示、スクリーンショットのゴミ箱への移動ができます。注釈エディタには、ペン、長方形、楕円、矢印、色、線の太さ、取り消し機能があります。編集内容を保存すると、元の画像と同じピクセル解像度で別の画像が作成されます。

## 画面収録

サイドバーの「**画面収録**」を開きます。ディスプレイまたはウインドウを選択してください。一部の範囲を収録する場合は、ディスプレイを選んでから収録する範囲を指定します。フレームレートを毎秒30または60フレームに設定し、システムオーディオを含めるかどうかとポインタの表示を選んで、「**収録を開始**」を押します。

収録中はメインウインドウが非表示になります。メニューバーには毎秒更新される経過時間と「**収録を停止**」が表示されます。エンコーダーの準備やメディアファイルの保存処理はバックグラウンドで実行されるため、操作への応答が妨げられません。**Control + Option + 4**で、どのアプリを使用していても収録を開始または停止できます。メインウインドウを開き直し、停止ボタンを使うこともできます。収録中にアプリを終了しようとすると、先に収録を停止して保存する選択肢が表示されます。

収録した動画はH.264のMP4形式で、スクリーンショットと同じ指定フォルダに保存されます。音声を有効にした場合はAAC形式で記録されます。システムオーディオは選択した収録対象に従って取り込まれます。マイクの音声は収録されません。ライブラリには、標準機能による動画再生、サムネイル、再生時間、お気に入り、共有、コピー、名前の変更、書き出し、ゴミ箱への移動機能があります。動画の書き出しではファイルをバックグラウンドでコピーするため、動画全体をメモリに読み込みません。

Retina動画は元の画面の細部を維持し、長辺は最大4096ピクセルとなります。H.264に対応するよう、縦横のピクセル数は偶数に調整されます。収録ストリームが中断された場合は、取得済みの使用可能なフレームで動画を完成させます。空の収録や失敗した収録はライブラリに追加されず、既存のスクリーンショットも引き続き使用できます。

収録と再生にはmacOSに付属するフレームワークを使用します。**FFmpeg、Homebrew、追加のコーデックのダウンロード、実行環境の追加インストールは不要です。**アプリケーションのコードはすべてアプリバンドルに含まれています。

## 言語と外観

「設定」には国旗付きの言語選択肢があり、英語（米国）、簡体字中国語（中国）、繁体字中国語（台湾）、日本語（日本）、韓国語（韓国）、フランス語（フランス）、ドイツ語（ドイツ）、スペイン語（スペイン）を選べます。標準では、Macの優先言語のうち対応している言語を使用し、該当する言語がなければ英語を使用します。変更はすぐに反映され、次回の起動時にも保持されます。

外観はライト、ダーク、システム設定に従うモードから選択できます。スクリーンショットとライブラリのメタデータはMac内に保存され、アプリがネットワークリクエストを送信することはありません。

## ビルド

XcodeまたはAppleのCommand Line Toolsをインストールしてから、次のコマンドを実行します。

```sh
python3 Tools/build.py
```

`build/EZSnapshot.app`が作成され、アイコンとローカライズされたリソースの追加、ローカルでの署名、インストーラーのデザイン素材の準備が行われます。ソースにはIDE用のSwift Packageも含まれています。`swift build`は実行ファイルを生成します。ビルドスクリプトは、通常のmacOSでの起動とプライバシー権限の許可に必要な、完全なアプリバンドルを生成します。

デザイン付きのドラッグ＆ドロップ式インストーラーをパッケージ化するには、ビルド時だけ使用するパッケージ作成ツールを一度インストールし、DMGを作成します。

```sh
python3 -m pip install --target .build/dmg-python -r Tools/requirements-dmg.txt
python3 Tools/make_dmg.py
```

`build/EZSnapshot-1.0-Apple-Silicon.dmg`が生成されます。配布前に、アプリケーションの署名とディスクイメージのチェックサムが検証されます。パッケージ作成ツールはアプリに含まれず、アプリの実行にも不要です。

別のツールチェーンを使用する場合は、`EZSNAPSHOT_TOOLCHAIN`にその`usr/bin`ディレクトリを、`EZSNAPSHOT_SDK`にMac SDKのディレクトリを設定してください。

ローカライズ、Retina画像の書き出し、スクリーンショットの保存、標準のH.264/AACエンコード、ライブラリの互換性、メディアの書き出し、リソースの検証には、次のコマンドを使用します。

```sh
python3 Tools/check.py
```

エンコードの検証には合成したフレームと音声を使用するため、画面収録の許可は不要です。自動化用のサンドボックス環境では、Appleの動画・音声エンコードサービスへのアクセスを許可する必要があります。実際の画面の撮影・収録には、引き続きmacOSの許可が必要です。

同梱のアプリにはローカルのアドホック署名が使用されています。一般公開する場合は、Apple Developer IDによる署名と公証が必要です。
